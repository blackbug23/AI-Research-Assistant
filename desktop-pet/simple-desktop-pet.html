📥 最快安装方法

下载 ZIP 包：

🔽 点击下载完整项目

下载后解压缩，无需任何安装步骤

简单步骤：

1 下载 ZIP 文件
2 解压缩到任意文件夹
3 打开 `desktop-pet` 文件夹
4 双击 `simple_main.js` 或 `index.html`

❌ 如果 npm install 失败

解决方案1：跳过 electron

npm install --no-optional

解决方案2：使用淘宝镜像

npm config set registry https://registry.npmmirror.com/ npm install

解决方案3：使用预构建包

npm install electron --prefer-offline

⚠️ Windows 常见错误

错误：electron 无法安装

解决方法：先安装 Windows 构建工具

npm install --global windows-build-tools npm install electron

错误：Python 缺失

解决方法：

npm config set python python2.7

错误：Visual Studio 工具缺失

npm config set msvs_version 2015
