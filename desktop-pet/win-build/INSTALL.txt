Windows 桌面宠物安装说明

========================================
步骤1：安装 Node.js
========================================
请先安装 Node.js（最新版本）
下载地址：https://nodejs.org/

========================================
步骤2：运行应用
========================================
1. 将 win-build 文件夹解压到任意位置
2. 进入文件夹
3. 双击运行 start.bat
4. 桌宠将出现在桌面右下角

========================================
功能说明
========================================
- 右键桌宠：弹出快捷菜单
- 托盘菜单：显示/隐藏、扫码、设置等
- 拖拽移动：鼠标拖拽桌宠到任意位置

========================================
常见问题
========================================
1. 桌宠不出现：检查 Node.js 是否安装
2. 扫码失败：手动输入QR码信息
3. PDF生成：需要PDF阅读器
