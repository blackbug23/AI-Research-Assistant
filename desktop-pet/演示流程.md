# QR码扫描入库系统演示流程

## 步骤1：启动应用
```bash
npm install
npm start
```

## 步骤2：QR码扫描
1. 点击"扫描QR码"按钮
2. 应用自动模拟QR码扫描
3. 数据自动入库（goods_name、quantity、supplier）

## 步骤3：入库结果
- goods_in表中添加新记录
- storage_location设置为NULL
- inventory表中更新库存数量

## 步骤4：定时检查
- 应用每5分钟自动检查goods_in表
- 查找storage_location为NULL的记录
- 发现未录入位置的商品

## 步骤5：桌宠提醒
- 桌宠开始摇动动画
- 出现气泡提醒："新到的XXX还没放好~"
- 显示"录入位置"和"忽略"按钮

## 步骤6：位置录入
1. 点击"录入位置"按钮
2. 应用模拟语音录入位置
3. 位置录入对话框显示"仓库A-货架1"等选项
4. 点击"更新位置"按钮，更新storage_location字段

## 步骤7：流程闭环
1. QR码扫描 → 入库
2. 定时器发现 → 提醒
3. 位置录入 → 更新
4. 检查goods_in → storage_location已录入
