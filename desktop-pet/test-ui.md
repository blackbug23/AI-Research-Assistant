✅ **Electron主进程与系统托盘**

2. 系统托盘包含完整菜单：显示/隐藏宠物、扫码入库、生成实验记录、设置、退出

✅ **桌宠本体：动画、拖拽与快捷气泡**
1. `index.html` 已实现桌宠形象，使用CSS动画（呼吸、摇晃、旋转、跳动）

✅ **实验记录采集向导UI**

4. 数据暂存逻辑：切换步骤不丢失数据

✅ **扫码入库与位置提醒UI**
