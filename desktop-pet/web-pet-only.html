📋 安装步骤

方法1：网页版本（最简单）

  1. 下载 `desktop-pet.tar.gz`
  2. 解压缩到任意文件夹
  3. 双击打开 `index.html`
  4. 桌宠就会出现在网页中

方法2：Node.js 版本

  1. 安装 Node.js（v18+）
  2. 下载 `desktop-pet.tar.gz`
  3. 解压缩
  4. 打开 PowerShell 或命令提示符
  5. 运行：npm install
  6. 运行：npm start

⚠️ 常见问题

1. npm install 失败

解决方案：

npm cache clean --force
npm install

2. Node.js 版本问题

请使用 Node.js v18+ 版本

3. electron 安装失败

可以先安装网页版本，无需 electron
